# Lunchify

Die App „Lunchify“ soll Mitarbeitenden eines Unternehmens ermöglichen, ihre Mittagsrechnungen digital einzureichen, um eine tägliche Rückvergütung eines Fixbetrags zu erhalten. Ziel ist es, den Prozess zu automatisieren und direkt über die monatliche Gehaltsabrechnung abzuwickeln. Die Anwendung wird intern entwickelt, um Kosten zu sparen und die Integration mit dem bestehenden Gehaltssystem zu erleichtern. Die Entwicklung erfolgt agil, damit Feedback aller Beteiligten frühzeitig einfließen kann. Die App wurde als Desktop-Anwendung umgesetzt und die erfassten Daten werden in einer Datenbank gespeichert.
